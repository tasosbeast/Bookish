# Current Task

## Task

Audit the current user-facing Bookish flows and identify the smallest remaining UX/product gaps before adding more architecture or infrastructure.

## Scope

Inspect only the user-facing frontend flows and the API contracts needed to understand them:

- discovery
- book details
- login/signup/logout/restoration
- My Books / shelves
- reviews and likes
- profile-related UI that currently exists

Do not refactor code and do not implement fixes in this task.

## Deliverable

Create a short prioritized list in your final response with at most 5 gaps.

For each gap include:

- what the user experiences now
- why it matters
- the smallest sensible fix
- rough risk: low / medium / high

Prioritize visible product value over engineering polish.

## Done when

- The audit is based on the current implementation, not assumptions.
- No code is changed.
- At most 5 gaps are reported.
- The top recommendation is small enough to become the next single `TODO.md` implementation task.
